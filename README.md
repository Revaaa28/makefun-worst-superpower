`/output/entry.txt` — an entry for make.fun's
[Worst Superpower](https://make.fun/c/u-suroto-worst-superpower-461dcdbe) bounty.

The line: *"I can heal any wound instantly — but only paper cuts, only on
Tuesdays, and only my own."* (88 characters, 90 bytes.)
